G3DGames

This is a repo that collects together all games in G3DGames in one place

The individual games are each in their own separate repos but you can use the Project Group in this one to build everything at once

To create a copy of this repo locally do the following...

> git clone https://github.com/G3DGames/G3DGames.git
>
> cd G3DGames
>
> git submodule init
>
> git submodule update

Once you've done this you can open G3DGames.groupproj to access all the games here
